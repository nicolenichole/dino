# dino

## Two Walls Jumper (TypeScript + Canvas, runs on localhost)

This is a minimal platformer prototype:
- A sprite can move left/right and jump.
- The sprite is constrained between two fixed vertical walls.

### Run locally

1. Install dependencies:
   - `npm install`
2. Start the dev server:
   - `npm run dev`
3. Open:
   - `http://localhost:5173`

### Controls

- Move: `A`/`D` or `ArrowLeft`/`ArrowRight`
- Jump: `Space` or `W`/`ArrowUp`
